# Conocimiento como proceso de conexión

Aunque todos tenemos ideas axiomáticas como parte de nuestro sistema de valores y en nuestra particular forma de comprender el mundo, el conocimiento elaborado, profundo, reflexivo, ese que le da forma al mundo que nos rodea, solo puede ser construido a través de las conexiones entre ideas, donde cada idea se fortalece a medida que se va tejiendo esa red con cada relación que hacemos y, al igual que una pieza de rompecabezas, solo tiene sentido para nosotros cuando lo integramos con el resto de las piezas y dependiendo de nuestra perspectiva de dicho rompecabezas.
