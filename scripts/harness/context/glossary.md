# Glossary

## Spark

Entrada inicial, extracto o idea cruda que puede detonar una nota.

## Reflective Session

Nota intermedia que conserva el proceso de pensamiento: señal, validación, voz propia y conexiones.

## Thing Note

Nota limpia, atómica y permanente orientada a conocimiento.

## Source

Nota fuente o extracto original.

## Atlas

Área curada del vault donde se ubican notas de conocimiento más maduras.
