# Project Brief — Cerebro

`cerebro` es un repositorio local para construir y mantener un sistema de conocimiento personal/operativo basado en Obsidian, Python y asistencia de modelos LLM.

El módulo principal actual es:

```text
scripts/cerebro_notes/
```

Contiene:

```text
core/        recursos compartidos
technical/  notas técnicas
reflective/ notas reflexivas, sesiones guiadas y Thing Notes
```

El sistema prioriza:

- local-first
- control por Python
- dry-run antes de write
- LLM como asistente, no como dueño del flujo
- Obsidian como interfaz final
- fuentes preservadas y movidas ordenadamente
