# Cerebro Notes Rules

La estructura conceptual es:

```text
core/        recursos compartidos
technical/  notas técnicas
reflective/ notas reflexivas
```

## Regla

Lo común sube a `core`.

Lo específico técnico queda en `technical`.

Lo específico reflexivo queda en `reflective`.

## LLM

El LLM sugiere:

- títulos
- señales
- preguntas
- tags
- conexiones tentativas
- resúmenes

Python decide:

- rutas
- nombres de archivo
- frontmatter final
- movimientos
- validación
- escritura
